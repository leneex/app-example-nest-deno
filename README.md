# NestJS on Deno

Example [NestJS](https://nestjs.com/) app running on [Deno](https://deno.com/). NestJS is a TypeScript framework for building scalable server-side applications on Node.js. Deno is a secure JavaScript and TypeScript runtime with built-in tooling and Node.js compatibility.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | `deno task start` |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# start the app
deno task start
```
